# Lufel S and A tier Personas: recommended skills at Skill LV 8

Retrieved September 26, 2026 (Pacific/Honolulu) from the live [English Persona guide](https://lufel.net/en/persona/). The page listed 155 Personas. This extract includes all **11 S-tier** and **17 A-tier** entries, with **161 recommendation rows**. Every detail page was checked with **Skill LV 8** active.

The 1st, 2nd, 3rd, and 4th labels are Lufel's recommendation priorities. Multiple skills at one priority are alternatives, not a requirement to equip every listed skill. A dagger (†) marks a skill labeled **Payment Event** on the page. Skill descriptions and values are in the glossary below. Active-skill values use the displayed LV 8 value. Passive descriptions still show their published rank arrays because Lufel does not collapse them to one value with the Skill LV selector.
